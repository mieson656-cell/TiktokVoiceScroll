# VoiceScroll — голосовое управление TikTok и YouTube

Android-приложение на Kotlin. Офлайн-распознавание русской речи через Vosk; управление жестами и доступными элементами интерфейса через Android AccessibilityService.

## Команды
- **«Дальше» / «Назад»** — следующий или предыдущий ролик (свайп).
- **«Пауза» / «Продолжить»** — переключить воспроизведение видео касанием центра экрана.
- **«Поиск [текст]»** или **«Найди [текст]»** — открыть поиск и ввести запрос.
- **«Лайк»** — нажать видимую кнопку лайка.
- **«Подпишись»** — нажать видимую кнопку подписки.
- **«Комментарий [текст]»** — открыть поле комментария и вставить текст. Комментарий автоматически не отправляется.
- **«Стоп»** — остановить голосовое управление.

Распознавание работает офлайн. Для поиска, лайков, подписок и комментариев службе специальных возможностей требуется доступ к содержимому активного окна. Тексты распознаются локально; приложение не отправляет их на сервер.

## Сборка
GitHub → Actions → Build APK → артефакт VoiceScroll-debug-apk.

Локально: JDK 17, Android SDK 35, затем `gradle :app:assembleDebug`.
